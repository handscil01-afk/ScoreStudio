# Sprint 4-G — 가사·코드 이름 입력

가사와 코드 이름은 이미 저장하고 그린다(`ScoreLyric`, `ScoreChordSymbol`). 이번 단계에서 그것을 입력하고 고치고 지울 수 있게 한다. 저장 형식은 바뀌지 않는다(스키마 15 그대로).

## 가사
### 데이터 규칙
- 가사는 음표(쉼표가 아닌 화음)에 절마다 하나씩 붙는다. 화음에서는 레이아웃이 읽는 첫 음(마디의 음표 목록에서 가장 앞)에 저장하고, 같은 화음의 다른 음에 있던 그 절의 가사는 지운다.
- 음절 뒤의 하이픈은 `Syllabic`으로 나타낸다. Begin·Middle은 뒤에 하이픈이 오고, Middle·End는 앞 음절에서 이어진다. 그래서 음절을 넣거나 고칠 때 **앞 음절**(같은 절, 같은 성부에서 그 앞에 가사가 있는 음)이 하이픈으로 끝나는지 보고 이 음절의 `Syllabic`을 정한다. 그리고 **뒤 음절**이 이 음절에서 이어지는지도 다시 맞춘다.
- `_`로 끝나는 음절은 연장선(`Extend`)을 단다. 연장선은 지금처럼 다음 음절이나 쉼표 앞까지 그린다.
- 음절 글자는 앞뒤 공백을 지우고 최대 40자다. 제어 문자는 받지 않는다.

### 명령 (ScoreEditor)
1. `SetLyric(음절, 절, 하이픈, 연장선)`: 대상 음표에 가사를 넣거나 바꾼다. 대상은 선택한 음표, 선택이 없으면 입력 위치의 음표다. 쉼표나 빈 곳이면 거절한다. 빈 음절은 그 절의 가사를 지운다. 앞 음절의 하이픈은 그대로 두고, 뒤 음절은 앞 음절이 하이픈으로 끝나면 거기에 이어진다("Hal- le- lu"에서 le를 지우면 "Hal- lu").
2. `EnterLyric(…)`: `SetLyric` 다음 **다음 가사 자리**를 선택한다. 다음 가사 자리는 같은 성부의 다음 음표 가운데, 앞 음에서 붙임줄로 이어진 음이 아닌 첫 음표다(마디를 넘는다). 쉼표는 건너뛴다. 없으면 선택을 그대로 둔다.
3. `EnterChordSymbol(글자)`: 대상 자리(선택한 화음·쉼표의 위치, 선택이 없으면 입력 위치)의 보표에 코드 이름을 넣는다. 같은 보표·위치에 있던 코드 이름은 바꾼다. 빈 글자는 그 자리의 코드 이름을 지운다. 그 다음 같은 성부의 다음 음표·쉼표를 선택한다(빈 마디면 다음 마디 처음으로 입력 위치를 옮긴다).
4. `TypeLyrics(친 글자, 절)`: `LyricTyping.Take`로 끝난 음절을 차례로 `EnterLyric`하고, 남은 글자를 돌려준다. 창의 가사 칸은 글자가 바뀔 때마다 이것만 부른다.
5. 모두 실행 취소할 수 있다. 거절되면 악보는 그대로다.

### 입력 글자 나누기 (`LyricTyping.Take`)
가사 입력 칸에 친 글자를 음절로 나눈다. Finale의 가사 입력처럼 공백과 하이픈이 다음 음표로 넘어가는 신호다.
- 공백: 앞 글자를 음절로 끝낸다(하이픈 없음).
- `-`: 앞 글자를 하이픈이 붙는 음절로 끝낸다.
- `_`: 앞 글자를 연장선이 붙는 음절로 끝낸다.
- 끝나지 않은 나머지 글자는 칸에 남는다. 한글 입력기가 글자를 조합하는 중에는 칸을 바꾸지 않는다(구분 문자가 들어왔을 때만 바꾼다).

## 코드 이름 글자 읽기 (`ChordSymbolText.TryParse`)
- 형식: 근음(A~G, 뒤에 `#`·`b`·`♯`·`♭` 하나) + 종류 + 선택적으로 `/베이스음`.
- 종류는 MusicXML 이름으로 저장한다: 없음 major, `m`·`min`·`-` minor, `7` dominant, `maj7`·`M7`·`Δ7` major-seventh, `m7`·`min7`·`-7` minor-seventh, `dim`·`o` diminished, `dim7`·`o7` diminished-seventh, `m7b5`·`ø`·`ø7` half-diminished, `aug`·`+` augmented, `sus4`·`sus` suspended-fourth, `sus2` suspended-second, `6` major-sixth, `m6` minor-sixth, `9` dominant-ninth, `maj9` major-ninth, `m9` minor-ninth. 그 밖의 종류(예: `7b9`, `add9`)는 other로 저장하고 글자는 그대로 그린다.
- 화면 글자(`Text`)는 친 그대로 두되 `♯`·`♭`은 `#`·`b`로 바꿔 저장한다(그릴 때 다시 ♯·♭로 바뀐다).
- 근음이 A~G가 아니거나, `/` 뒤가 음 이름이 아니거나, 20자를 넘으면 거절하고 한국어 이유를 알린다.

## 화면 (WPF)
- 오른쪽 "속성" 칸에 "가사"(절 선택 1~6절)와 "코드 이름" 입력 칸을 둔다.
- Ctrl+L: 가사 칸으로 간다. 선택이 없으면 입력 위치의 음표를 선택한다. Ctrl+K: 코드 이름 칸으로 간다.
- 가사 칸: 공백·`-`·`_`를 치면 음절을 넣고 다음 음표로 넘어간다. Enter는 남은 글자를 넣고 넘어가며, 빈 칸에서 Enter나 Esc를 누르면 악보로 돌아간다. 빈 칸에서 Delete는 선택한 음표의 그 절 가사를 지운다.
- 코드 이름 칸: 공백이나 Enter로 넣고 다음 음표·쉼표로 넘어간다. 빈 칸에서 Enter나 Esc는 악보로 돌아가고, Delete는 그 자리의 코드 이름을 지운다.

## 수용 기준
### 자동 테스트 (Core)
1. 음표 네 개에 "Hal- le- lu- jah"를 차례로 넣으면 Begin, Middle, Middle, End가 되고, 하이픈이 세 개 그려진다. 둘째 음절을 하이픈 없이 바꾸면 둘째는 End, 셋째는 Begin이 된다.
2. 한글 "주 님 의"를 넣으면 모두 Single이다. 붙임줄로 이어진 음과 쉼표는 건너뛴다. 마지막 음표 뒤에서는 선택이 그대로다.
3. 빈 음절은 가사를 지운다. 쉼표나 빈 곳에는 넣을 수 없다. 화음에서는 첫 음에만 저장된다. 2절은 1절과 따로 저장된다.
4. `LyricTyping.Take`: "Hal-le" → (Hal, 하이픈) + 남은 "le"; "가 나" → (가) + "나"; "sing_" → (sing, 연장선); 공백만 있으면 음절이 없다.
5. 코드 이름 읽기: C, Cm, F#m7b5, Bbmaj7/D, Gsus4, E♭7, Cadd9(other)는 받고, H7, C/X, 빈 글자는 거절한다. 넣은 코드 이름이 그 자리에 그려지고(B♭/D처럼), 같은 자리에 다시 넣으면 바뀌고, 빈 글자는 지운다.
6. 넣은 가사·코드 이름을 저장하고 다시 열면 같다. 실행 취소로 모두 되돌아간다. 모든 악보 규칙 검사(가사·코드 이름 겹침)를 통과한다.

7. `TypeLyrics`(가사 칸에 친 글자를 처리하는 함수, 창은 이 함수만 부른다): "Hal-le-lu-jah " 를 한 번에 넣으면 네 음표에 들어가고 남는 글자가 없다. "주 님" 은 "주"만 넣고 "님"을 남긴다.
