# Sprint 4-1 — 음표 그리기 1단계 설계와 수용 기준

## 범위
- 포함: 음표 머리(겹온·온·2분·4분 이하), 기둥, 꼬리(8분~64분), 점(최대 2개), 임시표(♯ ♭ ♮ 겹올림 겹내림), 덧줄, 쉼표(겹온~64분), 마디 온쉼표, 조표(시스템마다 반복, 마디 중간 조 바뀜), 화음과 2도 화음의 머리 엇갈림, 두 성부의 기둥 방향, 음표 수에 맞춘 마디 폭.
- 제외(다음 단계): 가사, 코드 이름, 붙임줄, 도돌이표·볼타, 빔(음표 잇기, Sprint 4-2a에서 구현), 잇단음표 숫자, 조가 바뀔 때의 제자리표, 쉼표 충돌 정리.

## 구조
| 단계 | 파일 | 하는 일 |
|---|---|---|
| 음악 계산 | `ScoreStudio.Core/Layout/Notation.cs` | 길이 → 음표 종류·점·잇단음표 여부, 철자/MIDI → 오선 위치, 조표의 음과 위치 |
| 준비 | `ScoreStudio.Core/Layout/NotePreparation.cs` | 마디마다 화음 묶기, 표시할 임시표, 기둥 방향, 2도 엇갈림, 임시표 칸, 필요한 간격 |
| 배치·그리기 | `ScoreStudio.Core/Layout/ScoreLayoutEngine.cs` | 마디 폭 결정, 시스템 늘리기, 좌표 계산, 그리기 목록 생성 |

WPF 렌더러는 바뀌지 않는다. 레이아웃이 만든 선과 기호를 그대로 그린다.

## 규칙
- **음 길이**: 잇단음표 묶음 안의 음은 묶음 비율을 곱한 값으로 찾는다(겹친 잇단음표 포함, Sprint 4-F). 그 밖에는 보통·점·겹점 값을 먼저 찾고, 없으면 3:2, 5:4, 6:4, 7:4, 2:3, 4:3, 9:8 잇단음표로 찾는다. 그래도 없으면(예: 붙임줄로 이어 붙인 길이) 그보다 짧은 가장 긴 값으로 그린다.
- **오선 위치**: 저장된 철자(예: `Eb5`)를 쓰고, 없으면 MIDI 음높이를 조에 맞춰 올림표 또는 내림표로 읽는다. 옥타브 아래 높은음자리표는 MusicXML처럼 실제 음높이로 계산한다.
- **임시표**: 조표와 같은 마디의 앞 음표로 정해진 값과 다를 때만 붙인다. 마디선을 넘으면 초기화한다. 붙임줄로 이어진 음표에는 다시 붙이지 않는다. 화음에서는 6도보다 가까운 임시표를 왼쪽 칸으로 옮긴다.
- **기둥**: 한 보표에 성부가 하나면 가운데 줄에서 먼 쪽을 기준으로 정한다(가운데 줄 음표는 아래로). 성부가 둘 이상이면 첫 성부는 위로, 나머지는 아래로 한다. 길이는 음표 머리 중심에서 3.5칸이며, 가운데 줄까지는 반드시 닿게 한다. 32분·64분음표는 꼬리가 들어가도록 더 늘린다.
- **간격**: 한 마디 안에서 모든 파트의 시작 시점을 모아 열을 만든다. 그래서 같은 박의 음표는 모든 파트에서 세로로 맞는다. 다음 시작 시점까지의 간격은 1.6 + 1.6 × log₂(1 + 2 × 길이[4분음표]) 칸이다(16분음표 2.5칸, 8분음표 3.2칸, 4분음표 4.1칸, 2분음표 5.3칸, 온음표 6.7칸). Finale과 비슷한 밀도가 되도록 Sprint 4-1b에서 줄였다. 임시표와 점이 들어갈 자리는 따로 더한다. 시스템을 오른쪽 끝까지 늘릴 때는 음표 간격에 비례해서 늘린다.
- **쉼표**: 온쉼표는 넷째 줄에 매달고, 나머지는 가운데 줄에 둔다. 두 성부일 때는 위·아래로 2칸씩 비켜 놓는다. 마디 전체를 채우는 쉼표는 마디 가운데에 온쉼표로 그린다.

## 수용 기준
### 자동 테스트 (`ScoreStudio.Core.Tests`)
1. 길이 → 음표 종류: 보통, 점, 겹점, 겹온음표, 셋잇단·다섯잇단음표를 맞게 찾는다.
2. 오선 위치: 다섯 가지 음자리표에서 기준 음의 위치가 맞다.
3. 조표: 올림표·내림표의 순서와 음자리표별 위치가 표준 기보와 같다.
4. 임시표: 조표에 있는 음에는 붙지 않는다. 같은 마디에서 반복되지 않고, 다음 마디에서는 다시 붙는다. 붙임줄로 이어진 음에는 붙지 않는다.
5. 같은 박의 음표는 모든 파트에서 x 좌표가 같고, 뒤의 박일수록 오른쪽에 있다.
6. 기둥 방향과 길이, 덧줄 개수, 마디 온쉼표의 위치, 2도 화음의 엇갈림이 맞다.
7. 모든 MusicXML 샘플에서 가져온 음표 수만큼 음표 머리가, 쉼표 수만큼 쉼표 기호가 그려진다. 그리기 항목은 페이지 밖으로 나가지 않는다.

### Windows 화면 테스트 (`ScoreStudio.Tests`, CI)
- 같은 페이지를 대상 기호를 넣고 한 번, 빼고 한 번 그려서, 레이아웃이 정한 자리에 실제로 잉크가 생기는지 확인한다(음자리표, 음표 머리). 글꼴 누락, 기준선 오차, 위치 오류를 잡는다.
- 미리보기 PNG를 "latest" 릴리스에 올린다.

### 수동 테스트 (Windows PC)
1. `samples/musicxml/`의 샘플과 실제 Finale 파일을 가져와서 음표, 쉼표, 조표, 임시표가 원래 악보와 같은지 본다.
2. 확대해도 기호가 깨지지 않고, 음표가 마디선이나 다른 음표와 겹치지 않는지 본다.
