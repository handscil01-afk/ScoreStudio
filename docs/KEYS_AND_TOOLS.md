# Finale식 도구와 단축키 설정

## 사용자 요구 (2026-10-14)
- 사용자가 키 설정을 원하는 대로 바꿀 수 있게 한다.
- 쓰는 사람이 Finale 사용자이므로 화면을 최대한 Finale와 비슷하게 한다. 중요한 것은 단축키 기본값, 도구 팔레트, 메뉴 구성과 이름, Simple Entry 팔레트다. 음표는 주로 **Speedy Entry**로 넣었다.

## Finale에서 확인한 것과 추정한 것
Finale 매뉴얼 사이트(usermanuals.finalemusic.com)는 이 개발 환경의 네트워크에서 직접 열리지 않아, 검색 결과에 나온 매뉴얼 발췌로 확인했다.
- **확인**: Speedy Entry는 숫자 키로 길이를 정해 음표를 넣는다(1=64분 … 5=4분, 6=2분, 7=온, 8=겹온). Enter는 입력 높이 표시(crossbar) 자리에 음을 더해 화음을 만든다. Delete는 음표·화음을 지우고, Backspace는 음을 쉼표로 바꾼다. + / - 는 반음 올림·내림, t는 다음 음과 붙임줄, 9는 딴이름한소리(엔하모닉), L은 기둥 방향 뒤집기, Ctrl+L은 기둥 방향 자동, Ctrl+숫자는 잇단음표(Ctrl+3 셋잇단), Shift+숫자는 입력 위치 앞에 끼워 넣기, Shift+↑↓는 위·아래 보표로 옮기기다. Simple Entry는 길이를 고른 뒤 음 이름 글자(A~G)로 넣는다.
- **추정** (사용자가 써 보고 맞춘다): Speedy Entry에서 ↑↓는 입력 위치가 음표 위면 그 음을 한 칸(줄·칸) 옮기고, 빈 자리면 입력 높이 표시만 옮긴다. Alt+↑↓는 음표 위에서도 표시만 옮긴다(화음에 더할 높이 고르기).
- 단축키는 모두 바꿀 수 있으므로, 추정이 틀려도 사용자가 바로 고칠 수 있다.

## 도구 (Finale 주 도구 팔레트)
화면 왼쪽에 Finale처럼 도구 팔레트를 세로로 둔다. 도구에 따라 악보를 누를 때와 키를 칠 때 하는 일이 달라진다.

| 도구 | 악보를 누르면 | 키 |
|---|---|---|
| 선택 | 음표·쉼표 선택, 빈 곳은 입력 위치 | 공통 키만 |
| Speedy Entry (처음 도구) | 누른 마디·높이에 입력 위치와 입력 높이 표시 | 공통 + Speedy 키 |
| Simple Entry | 누른 높이에 음표 입력(Shift: 화음에 더하기), 회색 미리보기 | 공통 + Simple 키 |
| 가사 | 누른 음표를 고르고 가사 칸으로 | 가사 칸 |
| 코드 | 누른 자리를 고르고 코드 이름 칸으로 | 코드 칸 |
| 조표 / 박자표 / 음자리표 | 누른 마디(음자리표는 그 음표 자리)에서 고르는 메뉴를 띄운다 | 공통 |
| 잇단음표 | 누른 음표부터 셋잇단음표를 시작한다 | 공통 |
| 표현, 아티큘레이션, 스마트 도형(이음줄 등), 반복, 마디, 텍스트 | 흐리게 두고 "아직 지원하지 않음"을 알린다 | — |

- 도구는 팔레트 버튼과 "도구" 메뉴로 고른다. 지금 도구는 눌린 버튼과 상태 표시줄에 보인다. 마지막 도구는 프로그램 설정에 기억한다.

## 메뉴 (Finale 메뉴 구성을 따름)
파일 · 편집 · 유틸리티 · 보기 · 문서 · 도구 · Speedy(또는 Simple, 가사 등 고른 도구의 메뉴) · 플러그인(흐리게) · 창 · 도움말.
- 파일: 새 악보, 열기, 저장, 가져오기(MusicXML, 악보 인식), 내보내기(PDF·MusicXML, 흐리게), 끝내기.
- 편집: 실행 취소, 다시 실행, 마디 복사·붙여넣기, 지우기, 단축키 설정.
- 유틸리티: 조옮김(반음·옥타브), 딴이름한소리, 기둥 방향(뒤집기·자동), 빔 다시 묶기(흐리게).
- 보기: 확대·축소, 100%.
- 문서: 조표·박자표·음자리표 바꾸기, 마디 추가·삭제, 페이지 크기.
- 도구: 위 도구 목록.
- 고른 도구 메뉴(Speedy): 붙임줄, 잇단음표, 마디를 넘는 음표 이어 넣기 설정 등 그 도구의 명령.
- 메뉴 이름은 한국어로 쓴다. Finale 한국어판의 정확한 이름은 확인하지 못했으므로 영어판 구성을 우리말로 옮긴다.

## 단축키
### 데이터 모델 (Core)
- `EditorCommand`: 편집 명령 목록(아래 표). 명령마다 범위(공통, Speedy, Simple), 한국어 이름, 묶음을 둔다.
- `KeyStroke`: 키 이름(WPF `Key` 이름, 예: `D3`, `NumPad3`, `OemPlus`, `Return`)과 Ctrl·Shift·Alt. 문자열로 "Ctrl+Shift+Z"처럼 저장·표시한다. 같은 키의 다른 이름(Enter/Return, PageUp/Prior)은 하나로 맞춘다.
- `KeyMap`: 범위별로 키 → 명령. 기본값(아래 표)에 사용자 설정을 덮어쓴다. 사용자 설정은 프로그램 설정(`settings.json`)의 `KeyBindings`에 **명령마다 키 목록**으로 저장하고, 기본값과 같은 명령은 저장하지 않는다. 그래서 나중에 명령이 늘어도 새 명령은 기본 키를 받는다.
- 찾는 순서: 지금 도구의 범위(Speedy 또는 Simple)에서 먼저 찾고, 없으면 공통에서 찾는다.
- 충돌: 같은 범위에서, 또는 공통과 도구 범위 사이에서 같은 키를 두 명령에 줄 수 없다. 새로 준 키는 앞 명령에서 빠지고 그 사실을 알린다.
- 실행(`CommandRunner`): 명령을 `ScoreEditor` 호출로 바꾼다. 창이 할 일(가사 칸으로 가기, 도구 바꾸기, 확대 등)은 창에 돌려준다.

### 기본값
| 범위 | 명령 | 키 |
|---|---|---|
| 공통 | 실행 취소 / 다시 실행 | Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z |
| 공통 | 마디 복사 / 붙여넣기 | Ctrl+C / Ctrl+V |
| 공통 | 이전 / 다음 음표 | ← / → |
| 공통 | 지우기(음표를 쉼표로) | Delete |
| 공통 | 선택 해제·취소 | Esc |
| 공통 | 옥타브 올림 / 내림 | Ctrl+↑ / Ctrl+↓ |
| 공통 | 잇단음표 2~7, 9 | Ctrl+2 … Ctrl+7, Ctrl+9 |
| 공통 | 가사 칸 / 코드 칸 | Ctrl+L(Simple·선택 도구) / Ctrl+K |
| Speedy | 64분 … 겹온음표 넣기 | 1 … 8 (숫자판 포함) |
| Speedy | 점 | . |
| Speedy | 화음에 음 더하기(입력 높이 자리) | Enter |
| Speedy | 음을 쉼표로 | Backspace |
| Speedy | 반음 올림 / 내림 | + (Shift+=, 숫자판 +) / - |
| Speedy | 한 칸 위 / 아래 (음표 위면 그 음, 아니면 입력 높이) | ↑ / ↓ |
| Speedy | 입력 높이만 위 / 아래 | Alt+↑ / Alt+↓ |
| Speedy | 위 / 아래 보표 | Shift+↑ / Shift+↓ |
| Speedy | 다음 음과 붙임줄 | T |
| Speedy | 딴이름한소리 | 9 |
| Speedy | 기둥 뒤집기 / 자동 | L / Ctrl+L |
| Simple | 음 이름 입력 / 화음에 더하기 | A~G / Shift+A~G |
| Simple | 온 … 32분음표 고르기 | 7 6 5 4 3 2 |
| Simple | 쉼표 넣기, 점 | 0, . |
| Simple | 한 칸 위 / 아래, 반음 올림 / 내림 | ↑ / ↓, + / - |
| Simple | 마우스 입력 켜기·끄기 | N |

- Speedy에서 Ctrl+L은 기둥 자동이므로, Speedy 도구에서 가사 칸은 가사 도구나 메뉴로 간다.
- Finale의 / (빔 끊기), ; (꾸밈음), H (숨기기), Shift+숫자(끼워 넣기)는 아직 지원하지 않는다. 키 설정 창에는 "아직 지원하지 않음"으로 보인다.

### Speedy Entry의 입력 높이 표시
- `ScoreEditor.Crossbar`: 다음 음을 넣을 높이(음계 번호). 입력 위치에 짧은 가로선으로 그린다.
- 처음에는 보표 가운데 줄 높이, 음을 넣거나 고르면 그 음(화음이면 가장 높은 음) 높이로 옮긴다.
- 숫자 키: 고른 것이 방금 넣은 음표가 아닌 음표면 그 음표의 길이를 바꾸고(Finale처럼), 아니면 입력 높이에 그 길이의 음표를 넣는다. 조표를 따른다.
- Enter: 고른 화음에 입력 높이의 음을 더한다. 이미 있는 음이면 그 음을 뺀다(마지막 음은 빼지 않는다).

### 키 설정 창 (편집 > 단축키 설정...)
- 범위·묶음·명령·키를 표로 보인다. 검색 칸으로 명령을 찾는다.
- 한 줄을 고르고 "키 더하기"를 누른 뒤 새 키를 누르면 더한다. "키 빼기", "이 명령 기본값", "모두 기본값"이 있다.
- 확인을 누르면 저장하고 바로 적용한다. 취소하면 바꾸지 않는다.

## 수용 기준
### 자동 테스트 (Core)
1. 기본값: 표의 키가 그 명령을 찾는다. 같은 범위에 겹치는 키가 없다. 모든 명령에 이름과 범위가 있다.
2. 사용자 설정: 키를 바꾸면 새 키가 그 명령을 찾고 옛 키는 아무것도 찾지 않는다. 충돌한 앞 명령에서 키가 빠진다. 저장하고 다시 읽으면 같다. 기본값과 같은 명령은 저장하지 않는다. 손상된 설정이나 모르는 명령·키 이름은 버리고 기본값을 쓴다.
3. 키 표기: "Ctrl+Shift+Z" ↔ 키, Enter/Return 같은 다른 이름을 맞춘다.
4. Speedy: 빈 마디에서 ↑↑ 5 5 → 입력 높이 두 칸 위의 4분음표 두 개. 음표를 고르고 ↑ → 그 음이 한 칸 위(조표에 맞게). 6 → 고른 음의 길이가 2분음표. Enter → 화음. Backspace → 쉼표. + → 반음 위. T → 다음 같은 음과 붙임줄. 9 → 딴이름(F♯ ↔ G♭). L / Ctrl+L → 기둥 방향 저장값. Shift+↓ → 아래 보표.
5. Simple: 지금의 키보드 입력 테스트가 그대로 통과한다(↑↓는 반음이 아니라 한 칸).

### Windows (CI)
- 키 처리 함수에 키를 넣어 Speedy·Simple 입력이 되는지, 바꾼 키가 적용되는지 확인한다.
