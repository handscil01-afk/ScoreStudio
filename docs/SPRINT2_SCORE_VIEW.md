# Sprint 2 — 악보 화면 설계와 수용 기준

## 범위
- 포함: 페이지 → 시스템(줄) → 보표 구조, 오선, 음자리표, 박자표, 마디선, 마디 번호, 파트 이름, 큰 보표의 중괄호, 여러 페이지, 확대/축소.
- 제외: 음표·쉼표·가사 표시(Sprint 4·5), 조표, 내용에 따른 마디 간격 계산(Sprint 5), 인쇄/PDF(Sprint 5).
- 음표 데이터가 있어도 아직 그리지 않는다. 화면에 "음표 표시는 아직 지원하지 않음"을 분명히 표시한다.

## 데이터 모델 변경 (스키마 버전 1 → 2)
| 대상 | 추가 항목 | 설명 |
|---|---|---|
| `ScorePart` | `Staves: List<ScoreStaff>` | 파트가 가진 보표 목록. 피아노는 보표 2개(높은음·낮은음). |
| `ScoreStaff` | `Clef: ClefType` | `Treble`(높은음), `Bass`(낮은음), `Alto`, `Tenor`, `Treble8vb`(테너 성부용 옥타브 아래 높은음자리표). |

- 버전 1 파일은 그대로 열린다. 이때 보표 정보가 없는 파트는 높은음자리표 보표 1개로 채운다.
- 저장은 항상 버전 2로 한다. 버전 1만 읽는 이전 빌드는 버전 2 파일을 "더 새로운 버전"으로 거절하므로, 보표 정보가 조용히 사라지지 않는다.
- 음자리표 값은 이름 문자열로만 저장한다. 숫자나 알 수 없는 이름은 손상된 파일로 처리한다.
- `ScoreProject.CreateNew()`는 4/4박자 빈 마디 4개를 가진 파트 1개로 시작한다.

## 레이아웃 구조
- 악보 데이터(`ScoreStudio.Core/Models`) → 레이아웃 엔진(`ScoreStudio.Core/Layout`) → 그리기 목록(선·기호·글자, mm 단위) → WPF 화면(`ScoreStudio/Rendering`).
- 레이아웃 엔진은 WPF를 참조하지 않는다. 그래서 Windows가 아닌 환경에서도 테스트할 수 있다.
- 좌표는 레이아웃 결과에만 존재하고, 프로젝트 파일에는 저장하지 않는다(개발 규칙 3).
- 기본값: 보표 간격(staff space) 1.75mm, 여백 15mm, 빈 마디 최소 폭 20 staff space.
- 시스템마다 들어갈 수 있는 만큼 마디를 채우고, 마지막 시스템을 뺀 나머지는 오른쪽 여백까지 늘린다.
- 페이지에 다음 시스템이 들어가지 않으면 새 페이지로 넘긴다.
- 음악 기호는 SMuFL 글꼴 Bravura로 그린다(`docs/THIRD_PARTY.md`).

## 수용 기준
### 자동 테스트 (`ScoreStudio.Core.Tests`)
1. 버전 1 파일을 열면 파트마다 높은음자리표 보표 1개가 생긴다. 저장하면 버전 2가 된다.
2. 보표·음자리표가 저장 후 다시 열어도 보존된다. 잘못된 음자리표 값은 한국어 오류로 거절한다.
3. 시스템마다 모든 파트의 보표가 있고, 각 보표 시작에 해당 음자리표가 있다.
4. 모든 마디가 정확히 한 번씩 배치되고, 순서가 유지된다.
5. 어떤 그리기 항목도 페이지 밖으로 나가지 않는다(중괄호 제외 여백 안).
6. 마디가 많으면 2페이지 이상이 되고, 두 번째 페이지부터 페이지 번호가 있다.
7. 박자표는 첫 마디와 박자가 바뀌는 마디에만 그린다.
8. 마지막 마디는 겹세로줄(끝세로줄)로 끝난다.
9. 파트나 마디가 없는 악보도 오류 없이 레이아웃된다.
10. A4 가로, Letter 설정에 따라 페이지 크기가 바뀐다.

### Windows 화면 테스트 (`ScoreStudio.Tests`, CI)
- 샘플 악보의 각 페이지를 실제 WPF 렌더러로 PNG를 만들고, Bravura 글꼴이 실제로 로드되었는지 검사한다.
- CI는 PNG를 "latest" 릴리스에 `preview-page-N.png`로 올려 사람이 확인할 수 있게 한다.

### 수동 테스트 (Windows PC)
1. `samples/sample-choir.scoreproj`를 열면 소프라노(높은음자리표) 1단과 피아노(높은음·낮은음자리표, 중괄호) 2단이 시스템마다 보이고, 2페이지 이상으로 나뉜다.
2. 17번째 마디에서 박자표가 3/4에서 4/4로 바뀌어 보인다.
3. 확대/축소: 도구 막대의 −, +, 배율 목록, Ctrl+마우스 휠, Ctrl+=, Ctrl+-, Ctrl+0이 동작하고, 확대해도 기호가 깨지지 않는다.
4. 제목이나 페이지 크기를 바꾸면 악보 화면이 바로 갱신된다.
