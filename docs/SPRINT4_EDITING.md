# Sprint 4 — 기본 편집(채보) 설계와 수용 기준

## 범위
이번 단계에서 하는 것:
- 키보드로 음표·쉼표 입력(음 이름 글자와 길이 숫자), 화음에 음 더하기
- 선택한 음표의 음높이 바꾸기(반음, 옥타브)와 길이 바꾸기
- 선택한 음표 지우기(같은 길이의 쉼표로 바뀜)
- 마디 추가·삭제, 마디 복사·붙여넣기
- 모든 편집의 실행 취소·다시 실행
- 마우스로 음표·쉼표를 눌러 선택하고, 마디를 눌러 입력 위치 정하기
- 입력한 8분음표 이하 음표의 자동 빔

이번 단계에서 하지 않는 것(화면에 "아직 지원하지 않음"으로 표시):
- 마우스로 오선 위를 눌러 음높이를 정해 입력하기
- 잇단음표 입력, 붙임줄·가사·코드 이름 입력, 조표·박자표·음자리표 바꾸기
- 여러 마디·여러 파트에 걸친 범위 선택

## 구조
편집은 `ScoreStudio.Core/Editing`의 `ScoreEditor`가 맡는다. WPF 창은 키와 마우스를 `ScoreEditor`의 명령으로 바꾸고, 결과를 다시 그리기만 한다. 그래서 편집 규칙은 모두 리눅스에서 자동 테스트할 수 있다.

### 상태
| 이름 | 내용 |
|---|---|
| `Project` | 편집 중인 악보(`ScoreProject`). 저장 형식은 바뀌지 않는다(스키마 변경 없음). |
| `Cursor` | 입력 위치: 파트, 보표, 성부, 마디, 마디 안의 위치(4분음표 단위 분수). |
| `Selection` | 선택한 화음 또는 쉼표 하나: 커서와 같은 칸(파트·보표·성부·마디·위치). 선택이 있으면 커서는 그 음표 위치에 있다. |
| `InputValue` | 다음에 입력할 길이: 음표 종류와 점 개수(기본 4분음표). |
| 실행 취소 기록 | 편집 전 악보·커서·선택의 사본. 최대 200개. 새 편집을 하면 다시 실행 기록은 지운다. |
| 마디 클립보드 | 복사한 한 마디(한 파트)의 음표들. |

### 명령과 규칙
1. **음표 입력** `EnterNote(음 이름)`: 커서 위치에 `InputValue` 길이의 음표를 넣는다.
   - 음높이: 조표를 따른다(사장조의 F는 F#). 옥타브는 같은 성부의 바로 앞 음표에 가장 가까운 쪽, 앞 음표가 없으면 보표 가운데 줄에 가장 가까운 쪽이다.
   - 덮어쓰기: 같은 성부에서 그 시간에 걸치는 음표·쉼표를 지운다. 뒤쪽이 남는 음표·쉼표는 남는 길이의 쉼표가 된다. 앞쪽이 걸치는 음표는 짧아진다.
   - 마디에 남은 길이보다 길면 기본으로는 입력하지 않고 이유를 알린다(악보와 실행 취소 기록은 그대로). 설정 메뉴의 "마디를 넘는 음표를 다음 마디로 이어 넣기(붙임줄)"를 켜면, 남은 만큼 넣고 나머지를 다음 마디(들)에 붙임줄로 이어 넣는다. 각 마디 안에서는 점이 하나까지인 음표들로 나누어 적고, 쉼표는 붙임줄 없이 나눈다. 마지막 마디를 넘으면 마디를 붙인다. 이 설정은 악보가 아니라 프로그램 설정(사용자 폴더의 `ScoreStudio/settings.json`)에 저장하며, 파일을 읽지 못하면 기본값을 쓴다.
   - 입력 후 새 음표를 선택하고 커서는 그 뒤로 간다. 마디 끝에 닿으면 다음 마디 처음으로 가고, 마지막 마디였다면 모든 파트에 마디를 하나 붙인다.
2. **쉼표 입력** `EnterRest()`: 음표 입력과 같지만 쉼표를 넣는다.
3. **화음에 음 더하기** `AddToChord(음 이름)`: 선택한 화음의 가장 높은 음 위로, 그 음 이름의 가장 가까운 음을 더한다. 쉼표가 선택되어 있으면 그 쉼표를 그 음의 음표로 바꾼다.
4. **음높이 바꾸기** `Transpose(반음 수)`: 선택한 화음의 모든 음을 옮긴다(↑↓ 반음, Ctrl+↑↓ 옥타브). 그 음과 붙임줄로 이어진 앞뒤 음(마디를 넘어도)도 함께 옮겨서 붙임줄이 끊기지 않는다. 음 이름 표기는 조표에 맞게 다시 정한다. MIDI 0~127을 벗어나면 하지 않는다.
5. **길이 바꾸기** `SetInputValue(종류, 점)`: 입력 길이를 정한다. 선택이 있으면 그 음표의 길이도 바꾼다.
   - 짧아지면 남는 시간은 쉼표가 된다.
   - 길어지면 같은 성부의 뒤쪽이 쉼표이거나 비어 있을 때만 그 시간을 차지한다. 뒤에 음표가 있거나 마디를 넘으면 하지 않고 이유를 알린다.
6. **지우기** `DeleteSelection()`: 선택한 화음을 같은 길이의 쉼표로 바꾼다. 쉼표를 지우면 아무것도 바뀌지 않는다.
7. **선택 옮기기** `SelectNext()`/`SelectPrevious()`: 같은 성부의 다음·이전 음표나 쉼표를 선택한다(마디를 넘어간다).
8. **마디 추가** `InsertMeasureAfter()`: 커서가 있는 마디 뒤에 빈 마디를 모든 파트에 넣는다. 박자·조표는 앞 마디를 따른다. 뒤 마디들의 번호는 하나씩 커진다(못갖춘마디처럼 원본 번호가 1부터 시작하지 않아도 그 차이를 유지한다).
9. **마디 삭제** `DeleteMeasure()`: 커서가 있는 마디를 모든 파트에서 지운다. 마디가 하나뿐이면 하지 않는다. 그 마디에서 시작하던 원본 줄·페이지 나눔(과 그 간격)은 다음 마디로 옮기고, 그 마디 끝에서 쓰이던 음자리표는 다음 마디 처음에 둔다. 도돌이표·볼타는 함께 지운다. 뒤 마디들의 번호는 하나씩 작아진다.
10. **마디 복사·붙여넣기** `CopyMeasure()`/`PasteMeasure()`: 커서가 있는 파트의 한 마디(모든 보표·성부)를 복사하고, 다른 마디에 덮어쓴다. 마디 길이가 다르면 붙여넣지 않는다.
11. **실행 취소·다시 실행** `Undo()`/`Redo()`: 악보와 커서·선택을 함께 되돌린다.
12. **자동 빔**: 편집한 성부·마디의 8분음표 이하 음표를 박마다 묶는다(단순 박자는 4분음표, 6/8·9/8·12/8은 점4분음표 단위). 쉼표에서 끊는다. 16분음표 이하의 둘째 빔은 이어지는 음끼리 잇고, 혼자 남으면 짧은 갈고리로 그린다. 편집하지 않은 마디의 원본 빔은 그대로 둔다.

### 화면(WPF)
| 키 | 동작 |
|---|---|
| C D E F G A B | 그 음 입력 |
| Shift + 음 이름 | 선택한 화음에 음 더하기 |
| 0 | 쉼표 입력 |
| 7 6 5 4 3 2 | 온·2분·4분·8분·16분·32분음표 길이(Finale Speedy Entry와 같은 번호) |
| . | 점 붙이기·떼기 |
| ↑ ↓ / Ctrl + ↑ ↓ | 반음 / 옥타브 올리기·내리기 |
| ← → | 이전·다음 음표 선택 |
| Delete, Backspace | 선택한 음표를 쉼표로 |
| Ctrl+Z, Ctrl+Y(Ctrl+Shift+Z) | 실행 취소, 다시 실행 |
| Ctrl+C, Ctrl+V | 마디 복사, 붙여넣기 |
| Esc | 선택 해제 |

- 도구 모음에 길이 버튼(온·2분·4분·8분·16분·32분음표, 점, 쉼표)을 Bravura 음표 그림으로 두고, 지금 입력 길이의 버튼을 눌린 상태로 표시한다. 버튼 그림이 상자 안에 잘리지 않고 그려지는지 Windows 화면 테스트로 확인하고, 그 그림을 `preview-input-toolbar.png`로 남긴다.
- 편집 메뉴에 실행 취소·다시 실행(할 수 있을 때만 켜짐), 마디 추가·삭제, 마디 복사·붙여넣기를 둔다.
- 선택한 음표는 반투명 파란 사각형으로, 커서 위치는 세로선으로 표시한다. 상태 표시줄에 커서 위치와 입력 길이, 거절된 편집의 이유를 보여 준다.
- 음표를 마우스로 누르면 선택한다. 음표가 없는 곳을 누르면 그 보표·마디에서 누른 곳의 오른쪽에 있는 첫 음표 앞에, 그런 음표가 없으면 이미 입력한 음표 뒤(빈 마디면 마디 처음)에 커서를 둔다.
- 저장하지 않은 편집이 있으면 창 제목에 *를 붙이고, 새 악보·열기·가져오기·닫기 전에 버릴지 묻는다.

### 화면 위치 정보(레이아웃)
마우스 선택과 선택 표시를 위해, 레이아웃이 페이지마다 그린 화음·쉼표의 상자(`PageLayout.Chords`: 파트·보표·성부·마디·위치·상자)를 함께 낸다. 음악 데이터에는 좌표를 저장하지 않는다(CLAUDE.md 규칙 3).

## 수용 기준 (`ScoreStudio.Core.Tests`)
1. 빈 4/4 마디에 C D E F를 4분음표로 넣으면 위치 0·1·2·3박에 C5 D5 E5 F5가 들어가고, 커서는 다음 마디 처음에 있다.
2. 사장조에서 F를 넣으면 F#이 된다. 낮은음자리표에서는 가운데 줄 근처(D3)부터 옥타브를 고른다.
3. 마디에 남은 길이보다 긴 음표는 넣지 않고 한국어 이유(설정 이름 포함)를 돌려준다. 악보와 실행 취소 기록은 그대로다. 설정을 켜면 4분음표 세 개 뒤의 2분음표는 4분음표+붙임줄+다음 마디 4분음표가 되고, 붙임줄이 그려지며, 음높이를 바꾸면 두 음이 함께 바뀌고, 실행 취소 한 번에 모두 되돌아간다. 쉼표는 붙임줄 없이 나뉜다. 설정 파일은 저장 후 다시 읽히고, 손상된 파일은 기본값이 된다.
4. 마지막 마디를 채우면 모든 파트에 마디가 하나 붙는다.
5. 2분음표를 선택하고 4분음표를 넣으면 4분음표와 4분쉼표가 된다.
6. 길이 바꾸기: 짧게 하면 쉼표가 생기고, 뒤가 쉼표이면 길게 할 수 있고, 뒤에 음표가 있으면 거절한다.
7. 지우기, 반음·옥타브 옮기기, 화음에 음 더하기가 규칙대로 동작한다.
8. 모든 편집을 실행 취소하면 처음 악보와 같아지고(JSON 비교), 다시 실행하면 편집 후와 같아진다. 새 편집을 하면 다시 실행할 수 없다.
9. 마디 추가·삭제 후 마디 번호가 1부터 이어지고, 마디 복사·붙여넣기가 내용을 그대로 옮긴다.
10. 8분음표 4개를 넣으면 박마다 둘씩 빔으로 묶이고, 8분음표·쉼표·8분음표는 묶이지 않는다. 점8분음표+16분음표에는 짧은 갈고리가 붙는다.
11. 편집한 악보를 저장하고 다시 열면 같은 악보가 된다. 편집 후에도 모든 악보 규칙 검사(빔, 겹침 등)를 통과한다.
12. 레이아웃의 화음 상자로 음표를 찾을 수 있다: 그린 음표 머리의 위치를 넣으면 그 음표의 칸이 나온다.

### 수동 테스트 (Windows PC)
1. 새 악보에서 키보드로 몇 마디를 입력하고, 실행 취소·다시 실행, 저장·다시 열기를 해 본다.
2. 가져온 악보에서 음표를 눌러 선택하고 음높이·길이를 바꾼다.
